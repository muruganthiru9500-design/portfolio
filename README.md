# Thirumurugan S - Portfolio

A modern, responsive portfolio website showcasing my projects and skills as a Computer Science student and web developer.

## Features

✨ **Modern Design** - Clean, dark theme with smooth animations
📱 **Responsive** - Fully responsive design for all devices
♿ **Accessible** - Semantic HTML and WCAG accessibility standards
⚡ **Performance** - Optimized for fast loading
🎨 **Smooth Animations** - Fade-in effects and smooth scrolling

## Sections

- **About** - Introduction and background
- **Skills** - Technologies and tools proficiency
- **Projects** - Featured projects with descriptions
- **Contact** - Ways to get in touch

## Technologies Used

- HTML5
- CSS3 (Grid, Flexbox, Animations)
- Vanilla JavaScript
- Responsive Design

## Live Demo

Visit the live portfolio: [https://thirumurugan.com](https://thirumurugan.com)

## Local Development

1. Clone the repository
```bash
git clone https://github.com/muruganthiru9500-design/portfolio.git
```

2. Open `index.html` in your browser

## Deployment

This portfolio is deployed on GitHub Pages. Any changes pushed to the `main` branch will be automatically deployed.

## Customization

To customize the portfolio:

1. Update the content in `index.html`
2. Modify colors and styling in `styles.css`
3. Update the contact links with your actual information
4. Add or remove project cards as needed
